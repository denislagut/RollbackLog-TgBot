# Rollback Log Telegram Bot

Бот на Node.js и grammY. Менеджер пакетов — Yarn.

## Запуск

Нужен Node.js 22+ и Yarn 1.22.22.

1. Установи зависимости: `yarn install`.
2. Скопируй `.env.example` в `.env`: `Copy-Item .env.example .env` в PowerShell.
3. Заполни `BOT_TOKEN` токеном из @BotFather.
4. Запусти `yarn dev` для разработки или `yarn start` для обычного запуска.
5. Напиши `/start` боту в личном чате.

Для будущей публикации постов добавь бота администратором канала с правом публикации и заполни `CHANNEL_ID`. Сейчас бот отвечает на `/start` и `/help`; публикация постов ещё не реализована.

## Структура

```text
src/
  index.js            # Точка входа и завершение процесса
  bot.js              # Создание бота и подключение обработчиков
  config/env.js       # Чтение и проверка окружения
  handlers/commands.js # Команды Telegram
  services/           # Будущая логика публикации и других задач
.env.example          # Шаблон настроек
```

`yarn run check` проверяет синтаксис исходников. `.env` исключён из Git; токен не следует публиковать.
