# Rollback Log Telegram Bot

Бот на Node.js, TypeScript и grammY. Менеджер пакетов — Yarn.

## Запуск

Нужен Node.js 22+ и Yarn 1.22.22.

1. Установи зависимости: `yarn install`.
2. Скопируй `.env.example` в `.env`: `Copy-Item .env.example .env` в PowerShell.
3. Заполни `BOT_TOKEN` токеном из @BotFather.
4. Запусти `yarn dev` для разработки или `yarn start` для обычного запуска.
5. Напиши `/start` боту в личном чате.

Добавь бота администратором канала с правом публикации и заполни `CHANNEL_ID` адресом **канала**, например `@my_channel`, либо числовым ID приватного канала. Имя бота сюда не подходит.

## Пост с голосованием

1. В личном чате с ботом отправь `/post`. Доступ есть у владельца канала и администраторов с правом публикации.
2. Отправь текст поста. Форматирование Telegram сохраняется.
3. По умолчанию под постом две кнопки: «Согласен» и «Не согласен». Для других вариантов отправь `/buttons За | Против | Воздержусь` (от 2 до 6 вариантов).
4. Бот покажет предпросмотр. Нажми «Опубликовать», чтобы отправить пост в канал. Старые подтверждения после редактирования не работают.
5. `/cancel` отменяет черновик. Новый текст до публикации заменяет текст текущего черновика.

Один пользователь имеет один голос в каждом посте. Повторное нажатие не увеличивает счётчик; выбор другой кнопки переносит голос. В предпросмотре голоса не учитываются.

Голоса сохраняются в `data/votes.json`. Не удаляй эту папку при обновлении и сохраняй её на постоянном диске при размещении на сервере. Черновики хранятся в памяти и исчезают после перезапуска. Запускай только один экземпляр бота. Пока поддерживаются текстовые посты.

`yarn test` проверяет повторные и параллельные голоса, смену варианта и сохранение результатов после перезапуска. Проверки не публикуют ничего в Telegram.

## Структура

```text
src/
  index.ts            # Точка входа и завершение процесса
  bot.ts              # Создание бота и подключение обработчиков
  config/env.ts       # Чтение и проверка окружения
  handlers/commands.ts # Команды Telegram
  handlers/posts.ts    # Черновики, предпросмотр и callback-кнопки
  services/publishing.ts # Отправка поста в канал
  services/votes.ts    # Хранение голосов и счётчики
.env.example          # Шаблон настроек
```

`yarn typecheck` проверяет типы. `yarn build` собирает проект в `dist`, после чего `yarn start:prod` запускает сборку. `yarn start` запускает TypeScript через tsx, а `yarn dev` также следит за изменениями.

Если запуск завершается с сообщением «Укажи BOT_TOKEN», создай `.env` по инструкции выше и добавь настоящий токен. `.env` исключён из Git; токен не следует публиковать.
